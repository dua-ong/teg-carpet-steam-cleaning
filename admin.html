How to Update the Live Site

This panel saves in your browser. Export JSON and send to developer to update the public website.
  1. Edit SEO, Media, Services, Location, Contact.
  2. Click Save All.
  3. Click Export JSON → teg-content.json downloads.
  4. Send that file to the developer.
  5. For images: upload to your host / CDN and paste the public URL (best for performance).
