How this works

Rule: If you upload or save a value in the panel, the live site uses it. If a field is empty, the site keeps the current HTML / default media (e.g. media/hero.mp4, text logo).
1. Run npm start (or Railway deploy)
2. Open /admin.html
3. Edit Branding, Contact, Media, SEO, Navs
4. Save All — writes data/content.json
5. Public site loads /api/content via site-config.js
Password: env ADMIN_PASSWORD or default teg2026. Change in production.
