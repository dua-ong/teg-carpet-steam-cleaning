How to Update the Live Site

Simple steps for a single person.

Current setup: This panel saves data in your browser (localStorage). To actually change the public website you need to export the JSON and give it to the developer, or replace the content in the site files.
  1. Edit SEO / Media / Services / Contact in the tabs.
  2. Click Save All.
  3. Click Export JSON — a file teg-content.json will download.
  4. Send that file to the developer (or open a GitHub issue / message).
  5. Developer will update the live site with your new content.

Password can be changed in the code later. Default is teg2026.
